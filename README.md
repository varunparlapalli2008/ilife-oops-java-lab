# OOPS Through Java Lab – Pending Coding Challenges

Solutions for Exercises 7–9 of the i-Life Ace It OOPS Through Java Lab.

## Programs

- `exercise-7/ThreadMessages.java` – threads using `Thread` and `Runnable`
- `exercise-7/AliveAndJoinDemo.java` – `isAlive()` and `join()`
- `exercise-7/DaemonThreadDemo.java` – daemon threads
- `exercise-7/ProducerConsumer.java` – producer/consumer synchronization
- `exercise-8/userpackages/PackageDemo.java` – user-defined package usage
- `exercise-8/LabelImageApp.java` – JavaFX label and image GUI
- `exercise-8/TipCalculator.java` – JavaFX tip calculator
- `exercise-9/JdbcConnectionDemo.java` – JDBC connection
- `exercise-9/JdbcInsertDemo.java` – JDBC insert with prepared statement
- `exercise-9/JdbcDeleteDemo.java` – JDBC delete with prepared statement

Console programs were checked with Java 21. JavaFX programs require the JavaFX SDK. JDBC programs use SQLite and require the SQLite JDBC driver.
